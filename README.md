# OSINT Catalog

## Запуск

Нужен Node.js 18 или новее. В PowerShell из папки проекта задайте пароль администратора (не короче 12 символов) и запустите сервер:

```powershell
$env:ADMIN_PASSWORD = 'замените_на_свой_длинный_пароль'
npm start
```

Откройте <http://127.0.0.1:3000>. Не открывайте `index.html` напрямую: IP-журнал и блокировка работают только через сервер.

## Панель администратора

Кнопка **Admin** открывает вход в панель. В ней можно добавить или снять блокировку точного IPv4- или IPv6-адреса, просматривать и очищать журнал. Журнал сохраняет IP-адрес и время загрузки каталога, без параметров URL; хранится не более 500 последних событий. Данные находятся в `data/admin-data.json` и исключены из Git.

Сервер берёт IP из сетевого подключения (`socket.remoteAddress`) и не доверяет заголовкам `X-Forwarded-For`. Поэтому за прокси журнал будет показывать адрес прокси; для получения адреса посетителя потребуется отдельно настроить доверенную прокси-конфигурацию. Для публичного доступа обязательно используйте HTTPS и настройте HTTPS-прокси перед Node.js-сервером; не публикуйте его напрямую в интернете. До запуска уведомите посетителей об обработке IP-адресов и соблюдайте применимые требования к приватности и срокам хранения.
